Reading the results: the fair test is G0 - S0 at the SAME epoch. Guidance off only 'really helps' unfamiliar handwriting if new writers / fresh boards are better at matched epochs, in both seeds' average, with an interval below 0. The layer diagnosis (diag_e15/, diag_e40/) says which parts the CTC loss pushes. RE and RL test whether sending the CTC loss only to early or only to late stages keeps (or beats) G0's result.
